# Facebook Page Launch Reference

## Baseline page configuration

- Use a clear niche name and matching handle.
- Use one original avatar/mascot and one sentence on the cover explaining the page benefit.
- Pin: page purpose, transparency/disclosure, and a question to collect pain points.
- Publish Reels publicly for discovery where appropriate.

## Content formats

| Format | Use it for | Risk control |
|---|---|---|
| Problem sketch | Discovery | Show a fictional, everyday situation |
| AI checklist | Trust | Cite only verifiable product facts |
| Product selection guide | Intent | State who should not buy it |
| Comment reply | Objection handling | Answer one question with no fake review |
| AI before/after illustration | Attention | Label as AI illustration; never imply a real result |
